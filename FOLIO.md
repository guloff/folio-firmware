# Folio

**Folio** — личная прошивка для **Xteink X4 Pro** на основе
[CrossPoint Reader](https://github.com/crosspoint-reader/crosspoint-reader) 1.6.5.
Задумана как «библиотека в кармане» и работает в паре с iOS-приложением **FolioLink**.

## Что добавляет Folio

| Где | Что |
|---|---|
| Главный экран | «Продолжить чтение» (обложка, прогресс, оценка оставшегося времени по личной скорости), недавние книги, календарь чтения за последние недели, нижняя панель: Библиотека · Полки · Статистика · Меню. Классический экран включается настройкой `folioHome`. |
| Статистика | Журнал сессий чтения (активное время, страницы) → сегодня против цели, серия дней, рекорд, итоги, календарь-heatmap. |
| Полки и статусы | Полки создаются в приложении и видны на читалке. Статусы ставятся сами: открыл книгу — «Читаю», дочитал — «Прочитано». |
| Выделения | Меню читалки → «Выделить» (или долгое нажатие на слово) → первое и последнее слово → сохраняется вместе с главой и процентом. В тексте выделения видны на светло-сером фоне (настройка «Показывать выделения в тексте»). Список — Меню → Выделения, оттуда можно перейти к месту в книге. |
| Личный словарь | Каждое найденное в словаре слово записывается с контекстом (для карточек в приложении). |
| Заставки | «Дашборд» (текущая книга, прогресс, цель, серия, календарь, итоги) и «Цитата» (случайное выделение). |
| Связь с телефоном | Меню → «Связь с телефоном»: подключение к сохранённой сети без лишних меню, запись Bonjour `_inklink._tcp`, API `/api/inklink/*`. Приложение ставит на читалке точное время. |
| Сопряжение | Телефон или браузер получает доступ на изменения по 6-значному коду с экрана читалки; без токена любые изменения (загрузка, удаление, настройки, WebDAV) отклоняются. Сброс — Меню → «Сбросить сопряжение». |
| Bluetooth | Настройка «Синхронизация по Bluetooth» (Система, по умолчанию выключена): приложение забирает статистику, сессии, книги, выделения и словарь и ставит часы без Wi-Fi. Доступ — по токену сопряжения через challenge-response (сам токен по радио не передаётся). Протокол — ниже. |
| Обновление | Прошивку можно загрузить из приложения; установка подтверждается на самой читалке. Образы подписаны ключом Folio (Ed25519): из приложения и по OTA (только релизы Folio) ставятся лишь подписанные, при ручной установке с SD неподписанный образ помечается «НЕ ПОДПИСАНО». |
| Язык | Дописан перевод на русский: 61 строка, которой не было в upstream (библиотека, жесты, часы и т. д.). |

Данные Folio лежат на SD в `/.crosspoint/inklink/`: `sessions.jsonl`, `highlights.jsonl`,
`vocab.jsonl`, `library.json`, `pairing.json` (только SHA-256 токенов). Это обычный текст, его легко прочитать и сохранить в резервную копию.

## Bluetooth (BLE) для FolioLink

Только X4 Pro. Радио поднимается после загрузки, если включена настройка; если при загрузке она была
выключена, включение срабатывает со следующего перезапуска (пробуждение из сна — тоже перезапуск).
На экранах Wi-Fi и перед сном BLE выключается. Полное описание — `PROJECT/notes/api.md`, раздел «BLE».

- Реклама: имя `Folio` + UUID сервиса, интервал ≈ 1 с, одно соединение.
- Сервис `F0110001-7B3A-4C8E-9F1D-6A2B5C4D3E01`: `F0110002-…` — запрос (Write with response, JSON ≤ 512 Б),
  `F0110003-…` — ответ (Notify; подписаться до первого запроса).
- Кадр ответа: `[seq u16 LE][flags: bit0 последний, bit1 ошибка][payload]`, размер = MTU − 3; склейка
  payload = тот же JSON, что у `GET /api/inklink/*`. До 64 КБ на ответ, списки продолжаются через
  `"more":true,"nextOffset":N` → повтор с `"offset":N`.
- Команды: `hello` → nonce, `auth{proof}` = HMAC-SHA256(SHA-256(токена), `"FOLIO-BLE-v1\n"`+nonce) (обязательна на каждое соединение; 5 неверных или 30 с без неё — разрыв), `info`, `stats`,
  `sessions{since,offset}`, `books{offset,limit}`, `highlights{book,since,offset}`, `vocab{offset}`,
  `screenshots{offset}`, `time{epoch,tzOffsetMin}`. Файлы по BLE не передаются.
- Проверка без устройства: `CROSSPOINT_SIM_BLE_LOOPBACK=<сценарий>` прогоняет команды через тот же
  диспетчер и кодировщик кадров в симуляторе (формат сценария — `src/inklink/BleLoopback.h`).

## Сборка

```bash
python3 -m venv ../.venv && ../.venv/bin/pip install platformio
git submodule update --init --recursive
../.venv/bin/pio run -e x4pro            # образ: .pio/build/x4pro/firmware.bin
```

Симулятор на Mac (SDL2: `brew install sdl2`), форк лежит в `../simulator`:

```bash
../.venv/bin/pio run -e simulator_x4_pro
python3 tools/inklink/make_test_books.py && python3 tools/inklink/seed_stats.py
CROSSPOINT_SIM_HTTP_PORT=18080 .pio/build/simulator_x4_pro/program
```

Подпись релиза (ключ вне репозитория, `$FOLIO_SIGNING_KEY_FILE` или `../secrets/`):

```bash
tools/inklink/sign_firmware.sh .pio/build/x4pro/firmware.bin   # → firmware.bin.sig
tools/inklink/sign_release.sh v0.2.0                            # подписать ассеты релиза через gh
tools/inklink/test_signature.sh                                 # хост-тест проверки подписи
```

## Как прошить (делает владелец, с Mac)

1. **Страховка.** Сначала сохраните полную копию флеш-памяти (crosspointreader.com → Debug → Read flash).
   Держите под рукой escape-hatch для X4 Pro: у X4 Pro нет кнопки Back, поэтому стандартная комбинация
   восстановления Back+Up не работает; в прошивке кнопка recovery — Down.
2. Первая установка: `pio run -e x4pro -t upload` по USB-C (или веб-флешер crosspointreader.com
   с файлом `firmware.bin`). У X4 Pro включён откат: если после прошивки снова загрузилась старая
   версия, прошейте ещё раз.
3. Дальше обновления идут по Wi-Fi: из приложения FolioLink или через «Обновление с SD».

> ✅ v0.1.0 установлена на живой X4 Pro (26.09.2026, веб-установщик, Custom .bin) и работает в штатном
> режиме. Образ занимает ~91 % OTA-слота (из них ~205 КБ — стек BLE). BLE в эфире и связь с iPhone ещё
> проверяются.

## Имена в сети и что по-прежнему называется crosspoint/inklink
- В сети читалка — `folio.local`, точка доступа — `Folio-Reader`, имя в роутере — `Folio-<MAC>`; UDP-поиск
  отвечает `folio (on …)` и, для плагина Calibre, `crosspoint (on …)`.
- Намеренно не переименованы (совместимость): папка данных на SD `/.crosspoint/` (прогресс, статистика,
  выделения), имена классов и макросов в коде (`CrossPointSettings`, `CROSSPOINT_VERSION`), протокол
  `/api/inklink/*`, заголовок `X-InkLink-Token`, сервис Bonjour `_inklink._tcp`, UUID BLE. Folio основана
  на CrossPoint Reader — упоминания автора upstream и лицензии сохранены.
